# Compatibility

Official target for 0.1.0:

- Linux x86_64
- OpenCode **2.x** (1.x fails closed)
- Native V2 config: `skills` array, `mcp.servers`, every MCP entry has `type`
- Python 3
- Node.js + npx (for shadcn MCP)
- git, curl, tar

Not claimed tested: macOS, Windows, OpenCode 1.x.

Optional: Chromium (`chromium`, `chromium-browser`, `/snap/bin/chromium`), `gh`, browser-act, serena, semgrep, osv-scanner, gitleaks.

Codebase Memory artifact is Linux amd64 only.
